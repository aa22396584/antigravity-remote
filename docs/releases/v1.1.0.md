### 🌟 本次發布核心亮點

#### 1. 🛡️ 徹底修復 5 大 P0 核心安全與控制可靠性缺陷
- **切換／刪除裝置目標一致性與原子清理 (#1)**：切換或刪除主機時強制銷毀舊連線與取消輪詢 Epoch，重置待審批隊列與終端日誌，杜絕指令誤發往非目標設備。
- **WebRTC DataChannel RequestID 配對與多工隔離 (#2)**：實裝唯一的遞增 `requestId`，終結 FIFO 盲配錯位風險；實體隔離控制頻道 (`0x00`)、Cascade 思考串流 (`0x01`) 與終端輸出 (`0x02`)。
- **在途非冪等操作寫入保護 (#3)**：嚴格區分連線前與在途異常，在 P2P 切換至 Relay 時禁止自動重複重送未獲確認的寫入操作（如 `rm`、`git commit`），消除重入危害。
- **審批遠端 200 OK 確認握手與狀態保留 (#4)**：審批動作等待遠端確認成功，失敗時完整保留審批卡片並允許再次操作，加入防連點防抖鎖定。
- **WebRTC P2P 握手 Fail-Closed 狀態機安全閘門 (#10)**：嚴格遵循 `unauthenticated` ➔ `challengePending` ➔ `authenticated` 握手狀態，未獲合法 Nonce 簽章 ACK 前全面封鎖業務資料流通。

#### 2. 🎨 P1/P2 UI/UX 與終端人機工程全面升級
- **聊天體驗與草稿還原 (#19, #20)**：`MessageDeliveryStatus` 狀態跟蹤、失敗重試、智慧草稿快照（Draft Snapshot）、桌面 Enter 送出與 Shift+Enter 換行。
- **智慧串流自動跟隨 (Smart Auto-Scroll)**：滑動檢視歷史記錄時解除強制置底，右下角浮動提供「回到即時 ⇣」按鈕。
- **響應式佈局與桌面適配 (#21, #22, #26)**：800dp 響應式斷點佈局，大螢幕 NavigationRail，`IndexedStack` 狀態跨頁籤保留，`Cmd/Ctrl+1/2/3` 全域快捷鍵。
- **終端 UTF-8 多位元組解碼與長時緩衝 (#23, #24)**：`Utf8ChunkDecoder` 解決中文與 Emoji 跨分包亂碼；分離 `sendRaw` 與 `sendInput`；1000 訊框有界環形緩衝區與截斷修剪；滿足 >= 44x44 無障礙點擊尺寸。
- **審批 Diff 語法著色與一鍵複製 (#27)**：`CodeDiffViewer` 支援 unified diff 高亮與行號顯示，一鍵複製 Diff / 變更代碼。
- **自適應重連與任務取消 (#25)**：1s~30s 隨機抖動指數退避重連；支援 `CancelCascadeTask` 中止遠端任務。

#### 3. 🔐 儲存降級、憑證安全與真實延遲量測
- **儲存降級橫幅 (#32)**：底層儲存異常時自動平滑回退至記憶體快取模式並彈出警示橫幅，確保零白屏崩潰。
- **診斷日誌脫敏 (#14, #31, #32)**：全面自動遮蔽 Bearer、OAuth Token、私鑰與私人指令，日誌匯出安全無虞。
- **真實延遲量測 (#6, #7)**：移除固定 28ms 假延遲，雙向 RTT 探針動態量測真實網路質量；嚴格隔離 Demo 與 Live 模式。
- **Deep Link 預覽防釣魚與嚴格 QR 解析 (#16, #17, #18)**：修復單引號 JSON 解析，外部跳轉彈出確認對話框防釣魚。

## 🌐 English Release Notes

**Antigravity Remote v1.1.0** marks a major milestone release, integrating all architectural enhancements from the **2026-09 Comprehensive Audit across 34 Issues**. It features battle-tested security primitives, fail-closed state machines, resilient dual-transport failover, and responsive desktop-class UI ergonomics.

### 🌟 Highlights & Key Deliverables

#### 1. 🛡️ 5 Core P0 Security & Control Reliability Defenses
- **Atomic Target Consistency (Issue #1)**: Immediate disposal of old transport pipelines, cancellation of in-flight polling loops, and clearing pending approvals/terminal buffers upon device switching or deletion.
- **RequestID Correlation & Stream Multiplexing (Issue #2)**: Eliminated naive FIFO response mapping by enforcing unique `requestId` dispatch; physically partitioned control (`0x00`), Cascade thought streams (`0x01`), and terminal byte frames (`0x02`).
- **In-Flight Write Protection (Issue #3)**: Prevents non-idempotent write RPCs (e.g., destructive terminal commands) from blind duplicate retransmission during P2P-to-Relay failovers.
- **Remote-Acknowledged Approvals (Issue #4)**: Non-blocking async approvals with remote 200 OK confirmation; retains pending cards upon failure and introduces concurrency debounce locks.
- **Fail-Closed WebRTC Handshake Gate (Issue #10)**: Strict enforcement of the `unauthenticated` ➔ `challengePending` ➔ `authenticated` state machine; completely blocks business packets until ECDSA NIST P-256 Nonce challenge verification succeeds.

#### 2. 🎨 UI/UX & High-Performance Terminal Ergonomics
- **Chat Composer & Draft Retention (Issue #19, #20)**: `MessageDeliveryStatus` lifecycle, inline retry, auto-draft snapshots, desktop Enter to send & Shift+Enter newline.
- **Smart Auto-Scroll**: Non-intrusive stream following that releases scroll lock during historical browsing, accompanied by a floating "Jump to Bottom ⇣" navigation button.
- **Adaptive Layout & Desktop State Preservation (Issue #21, #22, #26)**: 800dp responsive breakpoint switching between NavigationRail and bottom bar, `IndexedStack` view retention, `Cmd/Ctrl + 1/2/3` tab shortcuts.
- **Terminal Multi-byte UTF-8 Chunking & Bounded Buffer (Issue #23, #24)**: `Utf8ChunkDecoder` for pristine CJK and Emoji streaming across network packets; separation of `sendRaw` (raw keystroke tokens) and `sendInput`; 1000-frame bounded ring buffer with truncation indicators; >=44x44 touch targets.
- **CodeDiffViewer (Issue #27)**: Real-time unified diff hunk syntax highlighting with one-click copy.
- **Resilient Reconnect & Task Abort (Issue #25)**: 1s~30s Exponential backoff with 20% jitter; `CancelCascadeTask` integration.

#### 3. 🔐 Storage Fallback, Credential Redaction & Latency Telemetry
- **Graceful Storage Fallback (Issue #32)**: Seamless degradation to in-memory caching with visual banner alerts when persistent storage fails.
- **Sanitized Diagnostic Logs (Issue #14, #31, #32)**: Comprehensive scrubbing of Bearer tokens, ya29 credentials, and private keys.
- **Real-Time Latency Probing (Issue #6, #7)**: Replaced mock latency numbers with true bidirectional RTT telemetry; strict sandboxing between Demo and Live environments.
- **Deep Link & QR Parser Hardening (Issue #16, #17, #18)**: Single-quote JSON parsing fix, anti-phishing domain checks, and confirmation dialogs on external deep links.
